# Contributing

Office owns only its wrapper and CODE topology. Platform Collaboration owns
WOPI admission/protocol/persistence. Coordinate cross-repository contract changes;
do not restore an Office authority or weaken ordinary OAuth authentication.

Use Node 24 and npm. Run `npm ci`, `npm run check`, `npm run check:framing`
and the real platform warm `app-office` integration described in README.
Use generated original fixtures, never customer documents.
Maintain exact parent/child window and origin checks, launch context binding,
expiry/revocation, dirty-state guards and durable save correlation tests.

SDK changes require rebuilding and bundling the local archive with its lockfile
integrity. Dependency/image changes require lock updates, license inventory,
digest verification and repeated real browser round trips. Unit tests are not
format-fidelity or live integration approval.

PR checks are secret-free. Offline release packages are unsigned and cannot
authorize WOPI. Publishing, installing, deployment and signing-key operations
require separate owner approval. Never commit automatically.
